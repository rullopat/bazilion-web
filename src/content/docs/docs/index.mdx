Bazilion is a personal, open-source, **local-first multi-agent runtime** built
on [Pi's coding agent](https://www.npmjs.com/package/@earendil-works/pi-coding-agent)
as its core engine. Pi runs the per-turn loop, stores the JSONL transcript,
handles replay and compaction, executes providers and tools, and supplies the
coding tools.

Bazilion wraps that engine with a small daemon on your own machine, a workspace
under `~/.bazilion`, Agent templates, revisioned Team Templates, Teams, live
communication policy, shared files, memory, and messages — all under your own
control, with your own provider keys.

It is not a hosted platform. It is a daemon, a CLI, and a web UI you run
yourself, published under the MIT license.

**Bazilion 0.21.0-beta.1 ends the alpha clean-install era: homes upgrade in place.** Schema migrations run
forward on startup behind a verified pre-migration snapshot, web tokens carry per-device scopes, and a
`bazilion-pair://` setup code pairs a new device in one paste. The engine remains Pi 0.85.1. 0.20.x homes
upgrade automatically; 0.19.x and earlier are refused cleanly and need a reset.
Read [what changed in 0.21.0-beta.1](/docs/whats-new-0-21-beta-1/).

## How the pieces fit

<CardGrid stagger>
  <Card title="Agent templates become agents" icon="seti:config">
    A Profile is an Agent template — SOUL.md, IDENTITY.md, tools, skills mode,
    and a default model. Spawning it creates a permanent live Agent.
  </Card>
  <Card title="Pi runs the agent loop" icon="settings">
    Bazilion is based on Pi's coding agent for the session loop, transcript,
    compaction, provider/tool execution, and coding tools.
  </Card>
  <Card title="One reusable Team roster" icon="rocket">
    A Team Template owns revisioned stable slots and directed communication
    edges. Spawning a reviewed revision materializes its Agents atomically.
  </Card>
  <Card title="One effective live policy" icon="lock">
    Every Team owns exactly one revisioned policy. Edges allow directly or hold
    one typed attempt for approval; a missing edge denies during enforcement.
  </Card>
  <Card title="A mailbox between them" icon="email">
    Agents coordinate through a durable mailbox: `send_message`, `read_inbox`,
    and `wait_for_reply` in the loop, plus CLI, API, and web surfaces.
  </Card>
  <Card title="Shared memory, indexed" icon="magnifier">
    Each Team has one memory rooted at `<team>/memory`, indexed with qmd
    (BM25 over markdown) so every member can search it.
  </Card>
</CardGrid>
