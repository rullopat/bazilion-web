Bazilion is a local multi-agent runtime for one person. Agents run on
[Pi's coding agent](https://www.npmjs.com/package/@earendil-works/pi-coding-agent) with the LLM
provider of your choice: a ChatGPT login, an API key for OpenAI, Anthropic, Google and many
others, or a local LM Studio, Ollama or llama.cpp. They work in Teams that share a workspace,
memory and a mailbox, run on schedules, and are reachable from a web UI, a CLI and Telegram. One
daemon on your machine owns all state in `~/.bazilion`.

It is not a hosted platform: it is a daemon, a CLI and a web UI you run yourself, under the MIT
license.

**Bazilion 0.26.0** simplifies the product for a single local operator. It needs Node.js
`^26.12.1`, and a home from an earlier release is refused: back it up and start fresh, as
described in [Upgrade to 0.26.0](/docs/getting-started/#upgrade-to-0260). Read
[what changed](/docs/whats-new/#bazilion-0260). Linux is the tested platform; macOS runs commands
on the host and is untested.

## How the pieces fit

<CardGrid stagger>
  <Card title="Profiles become Agents" icon="seti:config">
    A Profile is an Agent template: SOUL.md, IDENTITY.md, AGENTS.md, TOOLS.md, a default model
    and skills. Spawning one creates an Agent with its own documents and conversations.
  </Card>
  <Card title="Pi runs the agent loop" icon="settings">
    Pi owns the turn loop, provider calls, compaction and the JSONL transcript. Bazilion adds
    Agents, Teams, credentials, tools and the daemon around it.
  </Card>
  <Card title="Teams share a workspace" icon="rocket">
    A Team is a directory (or a link to your project), a USER.md about you, shared memory and
    its members. Team templates spawn a whole Team at once.
  </Card>
  <Card title="Policy says who may message whom" icon="lock">
    An open Team lets members message each other freely; a restricted one needs an allow edge.
    You can always chat with every Agent.
  </Card>
  <Card title="A mailbox between them" icon="email">
    Agents message each other with `send_message`, `read_inbox` and `wait_for_reply`; an idle
    Agent with unread mail wakes up.
  </Card>
  <Card title="Shared memory, indexed" icon="magnifier">
    Each Team keeps Markdown notes in `<team>/memory/`, searched with qmd (BM25), so decisions
    outlive the chat that produced them.
  </Card>
</CardGrid>
