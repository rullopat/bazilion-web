Bazilion **0.23.0** is published on npm **latest** for the CLI, API types and client.
It remains **alpha in maturity**. The [GitHub release](https://github.com/rullopat/bazilion/releases/tag/v0.23.0)
names the exact released commit `b6d354b5e5e6bc8f82febd1a8047f7a7984c7443`.

## Read before upgrading

Use **Node 24.22.0+ within 24.x or 26.4.0+ within 26.x**. Earlier/other releases are refused
before opening state. Linux remains required for Agent execution; macOS installation and
management acceptance do not qualify macOS Agent turns.

**This is a clean-rebootstrap schema boundary, not an in-place upgrade from 0.22.0.**
Preserve the entire old home, paired database/auth identity and external Team work before any
operator-authorized reset. Old archives need their matching binary/schema, not an importer.
See [upgrade and reset guidance](/docs/getting-started/#upgrade-to-0230).

## Source-grounded research

Eligible interactive Agents can use daemon-owned native OpenAI/ChatGPT discovery, then read
original sources through guarded fetch and cite what was actually read. Managed browsing remains
an optional, separate capability, not a silent fallback. Status does not probe a provider or prove
search entitlement. Existing Agent/template model choices are not automatically changed.

The subscription journey has bounded historical acceptance; direct API-key native search stays
**experimental/live-unqualified**. Provider-hosted search networking is not confined by the
browser's proxy. Protected background/inbox/restricted turns gain no native-search or browser
capability; separately configured protected SearXNG discovery remains distinct.

## Private images stay recoverable without another generation

Completed, identity-bound private image captures can survive interrupted delivery without
becoming public. Team Results offers a minimal private inventory and quota totals, policy-gated
recovery and confirmed discard. Recovery can require communication approval; it never bypasses
policy, changes the original bytes or repeats a provider operation.

The required image qualification is **ChatGPT-only**, with its recorded historical evidence and
geometry limits. Direct OpenAI and OpenRouter routes remain implemented/offline-tested but
live-unqualified. This is not reference-image editing, guaranteed dimensions or social publishing.
See [saved images and recovery](/docs/results/#private-image-captures).

## Explicit workspace blockers

Team pages, CLI and API expose workspace blockers and limited recorded-cleanup attempts.
A cancellation or daemon restart is not proof that host commands stopped. Unknown ownership
stays blocked; there is no guaranteed recovery of abnormal host processes or manual lock clearing.
Scheduler/process acceptance also retains its limited scope, not a composed live content-Team
campaign. See [workspace ownership](/docs/coding-environment/#workspace-ownership-and-recovery).

## Engine and MCP

The bundled engine and standalone daemon-owned MCP client are **Pi 1.0.0**. Explicit tool admission
and disabled ambient discovery remain in place; this does not automatically enable Pi extensions.
Legacy MCP **SSE is retired**. **Streamable HTTP** remains available; **stdio execution is Linux-only**
and refuses before spawning on other platforms because owned process-tree retirement is required.
No automatic OAuth or replay of uncertain tool calls is added.

## Verified release, explicit provenance limit

Six exact-head Linux/macOS CI jobs and independent final acceptance preceded publication.
Public tar integrity, npm registry signatures and fresh public-byte library/CLI installations passed.
Installed npm and source pnpm dependency graphs differ; those checks are not interchangeable.

**Npm build attestations are not exposed for these versions**, despite the workflow requesting
them. The operator accepted completing the release with that limitation documented. Registry
signatures are verified, but are not build attestations; **no npm provenance badge is claimed**.
No republish, unpublish or version bump was used to conceal the limitation.

The [release checklist and evidence](https://github.com/rullopat/bazilion/blob/main/docs/testing/0.23.0-release-status.md)
retain initial failures and all qualification limits. No new provider/search/image campaign was
run during release closeout. BAZ-066 remains canceled; broader content-Team live/human work remains
unqualified. Read [0.22 changes](/docs/whats-new-0-22/) for historical context only.
